# 情报中心地域风控范围

## 结论

中国大陆法律、数据出境和来源服务器访问足迹的严格风控，只适用于中国大陆来源或中国大陆受监管数据流。

非中国大陆来源不套用中国大陆专属限制，但仍必须执行全球基础安全、账号授权、平台条款、配额、数据质量和审计控制。

## 一、中国大陆严格风控适用范围

满足任一条件即使用 `PRC_STRICT`：

- 数据源运营方或主要服务位于中国大陆；
- 中国大陆政府、官方机构、事业单位或中国大陆注册平台；
- 本人实名账号或 API 服务由中国大陆运营方提供；
- 数据被明确识别为中国大陆个人信息、重要数据或受限测绘地理信息。

不得仅凭一个 IP 地址或域名后缀判断国家范围。每个数据源必须在登记表中明确运营方、服务国家或地区和数据类别。

## 二、中国大陆来源执行的严格控制

- 中国大陆法律准入审查；
- 公开网页低频、串行、固定客户端；
- 本人登录后台默认优先官方 API、官方导出、本地执行或中国大陆固定执行点；
- 境外云登录中国大陆后台需要服务方明确允许；
- 同一账号或 Key 绑定主要执行来源；
- 跨工具共享额度和拒绝熔断；
- 401、403、429、验证码、WAF 或封禁后不得换 IP、账号、Key、Cookie、User-Agent 或执行平台继续；
- 中国大陆个人信息、重要数据和受限测绘数据执行跨境门禁；
- 保留来源服务器视角审计回执。

## 三、非中国大陆来源

非中国大陆来源使用 `GLOBAL_OPERATIONAL_BASELINE`，不再强制：

- 中国大陆境内固定执行点；
- 中国大陆专属境外 IP 和登录后台限制；
- 中国大陆公开网页默认 10 秒间隔、20 页、每小时 30 次；
- 中国大陆数据出境分类门禁；
- 中国大陆专属跨工具来源绑定规则。

非中国大陆来源按该服务方公开 API 文档、账号权限、服务条款、配额和技术限制运行。

## 四、所有国家都保留的基础安全

以下控制不是中国大陆法律专属，因此全球保留：

- Secret、Cookie、Token 和账号凭证隔离；
- 不使用他人或盗取的账号和凭证；
- 固定操作、参数 Schema 和响应 Schema；
- 请求量、分页、运行时间、响应体积和费用有界；
- 遵守服务方 401、403、429 和封禁信号；
- 不暴露任意代码、任意 Shell、漏洞利用和恶意扫描；
- 不允许未经批准的写入、交易、账户控制或删除操作；
- 数据质量验证、审计、停用和回滚。

这些基础控制用于保护你的账号、Key、费用、仓库和数据质量，不能因来源在境外而取消。

## 五、生产准入

每个数据源进入生产前必须明确标记：

```text
PRC_STRICT
或
GLOBAL_OPERATIONAL_BASELINE
```

国家或运营方无法确认时，先进入复审，不直接生产。确认是非中国大陆来源后，只执行全球基础安全和服务方自身规则。
