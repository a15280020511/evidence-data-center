# 情报中心全球工具雷达

机器权威分类：`INTELLIGENCE_TOOL_UNIVERSE.json`。

## 口径修正

情报中心需要收集的不是只有“提供数据的 API”。凡是能够增强公开情报发现、采集、读取、解析、规范化、检索、关联、证据化、安全和可靠性的免费工具、服务、协议、模型、数据集与资料，都属于候选范围。

候选入口包括：

- 公共 API、官方 SDK、托管免费工具；
- 远程 MCP、本地 MCP 候选、MCP 注册表和安全网关；
- 搜索引擎、语义搜索、新闻/论文/专利/法律/代码/数据集搜索；
- 浏览器、远程浏览器、无头浏览器、网页自动化与安全读取；
- 爬虫、RSS、Sitemap、变化监测、附件发现与网页归档；
- HTML、PDF、OCR、表格、Office、邮件、压缩包和多媒体解析；
- 翻译、语音转写、图像/视频处理、多语言 NLP；
- ETL、数据校验、Schema 推断、字段映射、单位与时间规范化；
- 实体消歧、去重、地址/公司/机构标准化和标识符交叉映射；
- RDF、知识图谱、证据图、时间线、引文图和关系图；
- 全文、向量、混合、地理和时间检索；
- GIS、遥感、STAC、COG、NetCDF、HDF5、WMS/WFS；
- STIX/TAXII、公开威胁情报、漏洞与供应链情报工具；
- 数据血缘、来源、快照、哈希、许可证、额度和证据包工具；
- OSV、SBOM、依赖、Secret、静态代码、许可证和容器安全工具；
- 测试、契约验证、回放、负载、日志、指标、追踪和可复现工具；
- 官方文档、协议规范、数据字典、分类法、研究方法和基准资料。

## 情报中心中的“计算工具”

情报中心允许使用为采集与证据准备服务的确定性计算：

- 哈希、校验和、计数、汇总、排名和指数构造；
- 描述统计、时间重采样、滚动汇总和质量诊断；
- 文本/向量相似度、实体候选生成、重复检测；
- 图结构构造、来源关系、时间线和基础图指标；
- 地理坐标转换、距离、面积和空间连接；
- 字段碰撞、数据比较、规则校验和异常候选标记。

正式统计推断、因果结论、优化、仿真、政策反事实、投资组合优化和战略博弈仍由断网计算中心负责。

## 搜索与发现来源

优先顺序：

1. 官方 API、MCP、包、模型、数据集和协议注册表；
2. 官方开发者门户、GitHub/GitLab 组织和文档；
3. PyPI、conda-forge、CRAN、Julia、npm、Maven、NuGet、RubyGems、crates.io、Go modules；
4. Hugging Face、OpenML、Zenodo、Software Heritage；
5. deps.dev、OSV、SBOM和软件供应链目录；
6. APIs.guru、CKAN、Socrata、ArcGIS、STAC、re3data、OpenDOAR；
7. Tavily、Exa、GitHub 和多语言本地搜索补漏；
8. 从已信任来源继续枚举文档、依赖、相关工具和替代品。

## 工具候选分类

每个候选必须保存：官方来源、版本、许可证、免费模式、Key、是否绑卡、是否自动超额、额度、平台、依赖、漏洞、维护度、文档、测试、资源消耗、与现有工具重叠、适合的中心和拒绝原因。

候选状态：发现 → 元数据核验 → 官方来源核验 → 免费门 → 安全审查 → 沙箱候选 → 基准候选 → 批准候选 → 晋级；也可进入观察、拒绝、废弃或淘汰。

## 自动化边界

自动流程可以读取公开注册表、官方文档、固定只读 API、Manifest 和锁文件，登记候选并发出 Server酱通知。

自动流程不得安装包、执行未知代码、启动本地 MCP、运行容器、安装浏览器扩展、授权 OAuth、提交密钥、开启计费或修改生产依赖。

## 更新周期

- 每日：新版本、停用、漏洞、许可/价格变化和高价值新工具；
- 每周：所有能力分类、生态和语言的平衡发现；
- 每月：免费额度、维护、安全和覆盖缺口审计；
- 每季度：前沿工具与现有工具基准竞争及淘汰评审。

## 原则

数据源和工具候选尽可能广收；生产工具必须少而精。不能因为热门、Stars 多或宣传强而晋级，必须填补能力缺口，或在质量、安全、维护、可复现、资源消耗和基准表现上明显优于现有工具。
