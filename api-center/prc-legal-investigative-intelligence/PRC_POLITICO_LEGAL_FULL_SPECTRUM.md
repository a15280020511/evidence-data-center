# 中国大陆政法—司法—纪检监察全景矩阵

## 定位

本矩阵用于把中国大陆公开或明确授权的政法、司法、纪检监察、专项刑事执法、院校培训、标准科研、理论研究和案例结果来源放在统一证据框架下，并与元典法条/案例召回、现行官方法源和既有电子证据矩阵协同。

“全覆盖”指覆盖重要公开来源族、组织层级和信息类型，并通过官方链接动态发现地方来源；不表示复制每一条记录，也不包含法院/检察/公安/国家安全/纪委监委内部专网、非公开培训、实名当事人案件后台或秘密侦查技术。

## 七层知识链

1. 规范与治理：法律、司法解释、党内法规、纪律/监察规则、跨机关联合规范。
2. 组织与职责：政法委、法院、检察、公安、国家安全公开法治、司法行政、纪委监委、专项执法机关。
3. 学校与培训：国家法官学院、国家检察官学院、公安院校、司法行政学院、中央司法警官学院、中国纪检监察学院及全国政法院校/法学院来源族。
4. 标准与科研：TC179刑事技术、电子物证、公安鉴定、检察技术、司法鉴定、证据科学、数字司法公开研究。
5. 办案与实践：公开程序、公开警务/检务/审判/监察材料、行政复议和执法监督。
6. 案例与结果：指导/参考/典型案例、裁判文书、检察技术案例、公安公开案例、纪委监委公开案件材料、鉴定案例、执行/破产/刑罚执行。
7. 理论与解释：中国法学会及研究会、机构媒体、专业期刊、公开论文和官方政策解释。

## 主干体系

- 党委政法委与政法政策协调；
- 国家立法、行政法规与司法解释；
- 人民法院；
- 人民检察院；
- 公安机关；
- 国家安全机关的公开法治来源；
- 司法行政；
- 纪委、监委、巡视巡察；
- 行政复议和行政执法监督；
- 知识产权、互联网、金融、海事、涉外等专项审判；
- 海警、海关缉私、移民管理等专项刑事/行政执法相邻来源；
- 省市县地方政法委、法院、检察、公安、司法行政和纪委监委。

## 源头视角与结果视角

源头视角从公开法律、组织职责、课程、培养方案、培训通知、标准、科研、教材目录和机构媒体中抽象“声明的能力与工作逻辑”。

结果视角从元典召回后经法院、检察、公安、纪委监委、司法鉴定等一手公开案件核验“实际出现的证据组合、程序和结果”。

任何高置信度结论至少需要一个一手官方来源，重要结论优先要求源头视角和结果视角交叉收敛；单一新闻或单一二手材料不得作为最终依据。

## 典型联合分析顺序

```text
具体问题
→ 元典法条/案例广泛召回
→ 政法治理与党内法规层
→ 纪委监委/监察层（如相关）
→ 法院/检察/公安/司法行政主干
→ 国家安全公开法治或专项执法相邻层（按主题触发）
→ 法官/检察官/公安/司法行政/纪检监察培训与理论研究
→ 刑事技术/电子物证/司法鉴定/检察技术标准科研
→ 公开案例结果层
→ 当前官方法律、司法解释和程序证据规则复核
→ 行业监管与专项红线
→ 防御性法律风险结论
```

## 自动化边界

允许：公开 API/Feed、官方批量下载、HTML/PDF/附件、公开数据库有界检索、官方链接动态发现和缓存增量。

停止：登录要求、验证码、WAF、403、429、平台拒绝、授权/条款不明确。

禁止：自动登录实名案件、破解验证码、绕过WAF、换IP/账号继续、隐藏API逆向、非公开课件、内部系统、秘密侦控参数、目标选择、侦查规避、反取证和证据销毁。

## 证据权重

1. 当前有效法律/行政法规/司法解释/正式党内法规和监察规范；
2. 法院、检察、公安、纪委监委、司法行政等一手官方案件和程序材料；
3. 官方标准、培训、科研和机构白皮书；
4. 中国法学会及机构专业研究、官方媒体；
5. 学术论文和其他二手材料。

元典承担召回，不单独控制最终结论。
