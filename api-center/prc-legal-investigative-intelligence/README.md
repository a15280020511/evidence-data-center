# 中国大陆法律、司法与电子证据联合情报目录

## 目标

为情报中心提供一个不重复建设爬虫的中国大陆法律合规审计入口。该目录把元典的法条/案例召回能力，与全国人大、最高法、最高检、公安电子数据规则、网信、市场监管、TC260、保密、自然资源、工信等公开官方来源组合起来。

本模块仅用于防御性合规、法律风险识别、证据完整性与审计准备。不得用于隐藏身份、规避依法调查、删除证据、绕过验证码/WAF/403/429、代理/IP轮换、隐藏接口扫描或私有接口逆向。

## 为什么不为每个官网重复写爬虫

现有 `web-retrieval` 已经提供受控的公开网页/PDF读取、搜索、提取和有限站点映射能力。新模块只负责：

1. 固定官方来源清单；
2. 权威等级；
3. 接入等级；
4. 元典与官方复核的顺序；
5. 选择现有 Provider 路由；
6. 在出现登录、验证码、WAF、403/429等信号时保持 fail-closed。

## 联合审计顺序

```text
具体工具/账号/行为/数据/用途
→ 情报中心 PRC 风险门
→ 元典：法条 + 案例广泛召回
→ 国家法律法规数据库 / 最高法 / 司法部：现行法条复核
→ 人民法院案例库 + 最高检：类案、证据与追诉实务
→ 公安电子数据规则：依法可调取/提取的电子数据及完整性要求
→ 网信 / 市场监管 / 工信 / 国家数据局 / 知识产权：行政与行业监管
→ TC260 / CNCERT：技术合规与安全风险
→ 国家保密局 / 自然资源部：国家秘密与测绘地理独立红线
→ GREEN / YELLOW / ORANGE / RED / REVIEW_BEFORE_PRODUCTION
```

元典是召回层，不是最终法律权威。最终结论必须结合当前有效的官方法条、司法材料、监管材料和具体平台授权条款。

## 接入规则

优先级：

```text
官方文档化 API
> RSS / Atom / Sitemap / 官方批量下载
> HTML / PDF / XLSX / CSV / JSON / XML
> 官方公开检索数据库的有界查询
> 现有受控 web-retrieval
> 人工或明确授权导出
```

禁止：自动登录、验证码破解、WAF绕过、拒绝后换IP/账号/Key/Provider、隐藏API逆向、无限分页和个人画像。

## 操作

- `catalog-capabilities`：读取本地能力目录。
- `source-catalog`：按主题、访问类别或证据权重筛选来源。
- `source-route`：获取某固定来源应复用的现有 Provider 路由。
- `joint-audit-plan`：按风险主题生成确定性的联合审计顺序。

## 典型使用

普通公开法条核验：国家法律法规数据库优先；元典用于发现相似法条和案例。

数据采集/爬虫/自动化争议：元典 + 最高法/最高检案例 + 市场监管典型执法 + 平台条款。

公安电子数据问题：公开的公安电子数据取证规则与两高一部电子数据规定仅用于理解依法取证范围、程序和完整性要求，不输出规避建议。

数据出境/个人信息：网信办现行法规与政策问答 + TC260技术指南。

高精度地理/测绘：自然资源部专项门。

涉密迹象：国家保密局专项门并直接升级审查。
