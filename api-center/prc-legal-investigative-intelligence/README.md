# 中国大陆法律、司法与电子证据联合情报目录

## 目标

为情报中心提供一个不重复建设爬虫的中国大陆法律合规审计入口。该模块把元典的法条/案例广泛召回能力，与全国立法、法院、检察、公安程序、司法行政、行政复议/执法监督、执行破产、专项审判及地方司法官方来源族组合起来。

本模块仅用于防御性合规、法律风险识别、证据完整性与审计准备。不得用于隐藏身份、规避依法调查、删除证据、反取证、绕过验证码/WAF/403/429、代理/IP轮换、隐藏接口扫描或私有接口逆向。

## 三张矩阵

### 1. `legal-system-matrix.json`：中国大陆法律体系矩阵

负责回答“这个问题属于中国大陆法治/司法体系的哪一条线，应查哪些官方来源”。当前覆盖：

1. 国家立法、行政法规与法源有效性；
2. 人民法院审判与司法公开；
3. 人民检察院检察监督与案件公开；
4. 公安侦查、行政案件与电子数据程序；
5. 司法行政与公共法律服务；
6. 行政复议、行政执法监督与监管执法；
7. 执行、破产重整与刑罚变更公开；
8. 知识产权、海事、涉外商事、互联网等专项审判；
9. 监察与职务犯罪衔接（相邻法治体系）；
10. 省市县地方司法机关官方来源族。

其中纳入的全国性官方平台/来源族包括国家法律法规数据库、全国人大、国务院公报、中国政府网、司法部行政法规/规章、最高人民法院、最高人民法院公报、人民法院案例库、中国裁判文书网、中国审判流程信息公开网、中国庭审公开网、中国执行信息公开网、人民法院公告网、全国企业破产重整案件信息网、减刑假释暂予监外执行公开来源、最高法知识产权法庭、涉外商事/海事审判来源族、最高人民检察院、12309中国检察网、公安部公开程序规则、司法部、12348中国法律服务网、司法行政案例库、全国行政复议服务平台以及律师/法律援助/公证/司法鉴定/人民调解/仲裁/社区矫正等司法行政来源。

实名当事人服务与公开情报严格分开：12309案件查询、审判流程个案查询、在线行政复议申请等能力只登记，不由情报中心自动登录或提交。

### 2. `investigative-evidence-matrix.json`：法律依据与证据/侦查类别矩阵

负责回答“依法可能涉及哪些电子数据、程序、证据完整性和调查类别”。只保存公开法定类别和程序边界，不保存技术侦查具体实现或规避方法。

### 3. `source-catalog.json`：基础来源与专项监管目录

保存元典、网信、市场监管、TC260、保密、自然资源、工信等基础来源，并继续作为专项法律风险路由层。

## 元典与官方来源的职责分工

```text
具体问题
→ 元典：法条/案例大范围召回、同义词扩展、相似事实发现
→ legal-system-matrix：确定应进入哪些司法/法治体系主线
→ 国家法律法规数据库/全国人大/国务院/司法部：法条效力与现行文本
→ 法院/检察/公安/司法行政官方来源：程序、案例、文书、执行、听证、鉴定、复议等实务复核
→ investigative-evidence-matrix：证据类别、完整性、归因和法定程序边界
→ 行业监管/专项红线：网信、市监、工信、保密、自然资源等
→ 平台授权/合同/数据权利复核
→ GREEN / YELLOW / ORANGE / RED / REVIEW_BEFORE_PRODUCTION
```

元典是召回层，不是最终法律权威。指导性/典型案例也不能代替法律或司法解释作为最终法源。材料用于高风险结论前必须回到当前有效的官方文本。

## 当前法律基线

法律结论必须先经元典广泛召回，再以当前官方来源核验有效性。2026-08 的重点基线包括：

- 宪法、立法法；
- 人民法院组织法、人民检察院组织法、法官法、检察官法、人民陪审员法；
- 刑法、民法典；
- 刑事诉讼法、民事诉讼法、行政诉讼法、国家赔偿法；
- 行政复议法及现行实施规则、行政处罚法、行政强制法、行政许可法；
- 《公安机关办理刑事案件程序规定》及现行公安行政案件程序；
- 《关于办理刑事案件收集提取和审查判断电子数据若干问题的规定》等电子数据规则；
- 网络安全法2025修正文本（2026-01-01施行）、数据安全法、个人信息保护法、网络数据安全管理条例；
- 反电信网络诈骗法、治安管理处罚法2025修订文本；
- 反不正当竞争法2025修订文本；
- 律师法、法律援助法、公证法、人民调解法、仲裁法、社区矫正法、监狱法及司法鉴定规则；
- 监察法2024修正文本（2025-06-01施行），仅作为职务犯罪衔接的相邻法治层；
- 保守国家秘密法2024修订文本及现行实施条例。

## 全国司法公开与法律服务覆盖

法院侧矩阵不只读取最高法正文站。最高法公开规则所列的审判流程、庭审活动、裁判文书、执行信息等司法公开平台，以及全国企业破产重整、减刑假释暂予监外执行等专项公开来源均纳入矩阵。人民法院案例库用于高权重类案参考，中国裁判文书网用于已公开裁判文书的有界查询，执行/公告/破产等平台分别承担对应公开信息。

检察侧同时覆盖最高检指导性案例、典型案例和12309中国检察网的公开法律文书、重要案件信息、检察听证公告等；实名案件查询仍属于当事人授权服务，不自动化。

司法行政侧同时覆盖司法行政（法律服务）案例库。其公开案例横跨人民调解、法律援助、公证、司法鉴定、社区矫正、律师、戒毒、监狱、行政执法监督、仲裁等类别。行政复议另接全国行政复议服务平台及司法部持续发布的典型案例。

## 防御性证据/侦查类别

模块只描述法律上公开可知的类别和程序边界，不描述技术侦查的具体实现能力、部署方式、识别弱点或规避方法。矩阵包括：

- 身份、账号与现实主体关联；
- 登录、访问、通信、域名解析、云服务和应用审计日志；
- 短信、邮件、即时通信、公开网页、云文件等通信与内容电子数据；
- 银行、支付、商户和交易记录；
- 手机、计算机、磁盘等设备与原始存储介质；
- 网络在线提取、远程电子数据和云端记录；
- 依法调取以及平台/运营商依法提供技术支持和协助；
- 勘验检查、搜查、查封扣押、证据保全；
- 查询、冻结与数据保全；
- 鉴定、辨认和专门性审查；
- 技术侦查的法定适用、严格审批、范围、期限和用途限制；
- 网络数据行政监管检查；
- 多来源同一性/关联性判断；
- Hash、备份、封存、录像、访问日志、数字签名/证书、来源时间等完整性和证据链；
- 国家秘密、商业秘密、个人隐私/个人信息的保密、范围和用途限制。

## 接入规则

优先级：

```text
官方文档化 API
> RSS / Atom / Sitemap / 官方批量下载
> HTML / PDF / XLSX / CSV / JSON / XML
> 官方公开检索数据库的有界查询
> 现有受控 web-retrieval
> 人工或明确授权导出
```

禁止：自动登录、验证码破解、WAF绕过、拒绝后换IP/账号/Key/Provider、隐藏API逆向、无限分页、个人画像、反取证和侦查规避。

对于中国裁判文书网、人民法院案例库、执行信息网等检索型系统，只做有界查询、增量检索和缓存；遇登录、验证码、403、429或平台拒绝即停止。地方法院/检察院/司法行政来源必须经中央官方或政府官方链接发现并校验主域名，不维护灰色镜像。

## 操作

- `catalog-capabilities`：读取能力目录和三张矩阵摘要。
- `source-catalog`：按主题、访问类别或证据权重筛选基础/专项来源。
- `source-route`：获取基础来源应复用的现有 Provider 路由。
- `legal-system-matrix`：按司法体系主线或主题读取全国法律体系、官方平台、法源家族和元典联合复核路径。
- `investigative-evidence-matrix`：读取/筛选现行法律层与防御性证据/侦查类别。
- `joint-audit-plan`：按风险主题生成元典 + 法律体系主线 + 官方法条 + 程序 + 电子证据 + 案例/文书/执行 + 监管 + 红线 + 证据类别映射的联合审计顺序。

## 典型使用

普通法条核验：元典召回 → 国家法律法规数据库确认现行文本与效力。

民商事/行政争议：元典类案召回 → 人民法院案例库/最高法 → 中国裁判文书网有界补充 → 对应实体法和程序法。

刑事/公安电子数据问题：元典案例召回 → 刑诉法 + 公安刑事程序 + 两高一部电子数据规定 + 最高法/最高检公开案例；只用于理解依法取证范围、程序和完整性。

执行/企业风险：执行信息公开 + 人民法院公告 + 全国企业破产重整信息 + 裁判文书/案例库交叉核验。

检察监督：最高检指导/典型案例 + 12309公开文书/重要案件/听证 + 当前法律和司法解释。

行政执法争议：全国行政复议服务平台/司法部行政复议典型案例 + 行政执法监督 + 行业监管执法案例。

鉴定/证据真实性：司法部司法鉴定规则、技术规范和案例 + 电子数据完整性矩阵。

高精度地理/测绘：自然资源部专项门。

涉密迹象：国家保密局专项门并直接升级审查。
