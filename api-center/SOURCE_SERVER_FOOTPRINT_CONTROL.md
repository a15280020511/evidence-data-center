# 来源服务器视角访问足迹封控标准

## 1. 目标

情报中心不仅控制自身取得、保存和传输的数据，还必须从被访问网站、API和数据库运营者的视角控制访问行为。

来源服务器通常能够记录：

- 出口 IP、国家或地区、云服务商和 ASN；
- TLS、浏览器和自动化指纹；
- User-Agent、Accept、Referer 和其他请求头；
- 账号、API Key 标识、Cookie、Session 与设备关联；
- 请求时间、频率、并发、分页、下载量和访问路径；
- 401、403、429、验证码、WAF、封禁页及后续重试；
- 同一账号在不同 IP、云平台和设备之间的切换。

封控目标不是隐藏身份或者伪装成人工用户，而是形成合法、稳定、低频、最小、可解释且遇拒即停的访问轨迹。

## 2. 原点案例共同雷区

原点案件反复出现以下组合：

1. 未经授权或者超越授权取得数据；
2. 使用程序、外挂、自建账号、中转服务、Cookie 或其他技术手段；
3. 服务方采取限制或安全措施后继续规避；
4. 多账号、多终端、多 IP 或代理切换；
5. 高频、批量、持续下载或者向多人提供访问；
6. 获取认证信息、非公开数据、高精度数据或完整数据库；
7. 形成替代服务、出售数据或者规模化牟利。

境外 IP、云 IP 或自动化工具本身不等于违法。风险来自授权、手段、规模、拒绝信号、用途和后果的组合。

## 3. 出口分类

每个数据源必须登记一个执行出口类别：

- `OFFICIAL_API_CLOUD`：官方 API，从固定云执行器调用；
- `PUBLIC_WEB_CLOUD`：无需登录的公开网页，由固定只读云浏览器访问；
- `AUTHORIZED_LOCAL`：本人授权后台，由用户本地环境执行或官方导出；
- `PRC_FIXED_RUNNER`：经审计的中国大陆固定执行点；
- `MANUAL_EXPORT`：人工登录并使用官方导出功能；
- `BLOCKED`：不存在合法、稳定的执行路径。

不得使用住宅代理、代理池、随机 IP、反指纹、验证码破解或自动 Unblock 来改变来源服务器看到的访问来源。

## 4. 中国大陆数据源出口规则

### 官方 API

本人实名 API 可以从固定云出口调用，但必须满足：

- 服务条款未限制境外或云端访问；
- 不要求绑定中国大陆固定 IP；
- 只调用官方文档中的固定端点；
- 账号绑定一个主要执行来源，不在多个云平台之间轮换；
- 遵守单账号总额度和服务方限流。

### 无登录公开网页

可以使用 GitHub、Cloudflare、Browserless 等固定云出口，但必须：

- 固定域名、固定公开路径；
- 单任务串行，默认并发为 1；
- 使用稳定 User-Agent，不随机轮换；
- 设置每域名请求预算、最小间隔、最大页数和响应上限；
- 不访问登录接口、隐藏接口、移动端私有接口或调试接口；
- 遇到验证码、WAF、封禁、401、403 或 429 后停止。

### 本人会员后台或登录网站

默认禁止由境外云浏览器直接登录和批量采集。优先顺序为：

```text
官方 API
→ 官方导出、SFTP 或授权镜像
→ 用户本地正常登录与导出
→ 经审计的中国大陆固定执行点
→ 数据不足回执
```

只有服务方明确允许云端自动化、境外访问和相应数据处理时，才能为该数据源单独批准固定云出口。

## 5. 身份与出口一致性

- 一个实名账号或 API Key 只能绑定一个主要执行来源类别；
- 同一任务不得在 GitHub、Cloudflare、Browserless、Apify 和其他执行器之间切换来源；
- 同一来源收到拒绝后，其他工具必须共享熔断状态；
- 不得通过换 IP、Key、账号、Cookie、Header、User-Agent 或执行平台改变拒绝结果；
- 不得让多个工具各自消耗一份额度，实际形成跨工具叠加采集。

## 6. 请求足迹

公开网页默认控制值：

- 最大并发：1；
- 最小请求间隔：10 秒；
- 单任务默认最大页面数：20；
- 单域名每小时默认最大请求数：30；
- 自动重试：仅网络超时和 5xx 可在同一来源、同一身份下有限重试；
- 401、403、429、验证码、WAF、封禁页：不得在同一任务自动重试。

官方 API 以服务方公开额度为准，但仍必须执行单账号全局计数和跨工具合并计数。

数据源可以通过审计批准更严格或更宽松的专用额度；不得由任务票据自行扩大。

## 7. User-Agent 与浏览器指纹

- 使用固定、真实、稳定的客户端标识；
- 不随机轮换 User-Agent；
- 不伪造手机、不同浏览器或不同设备群；
- 不修改 TLS 指纹、Canvas、WebGL 或其他浏览器指纹以规避识别；
- 不提交虚假来源页、虚假 X-Forwarded-For 或伪造客户端 IP；
- 不在请求头中暴露内部任务内容、Secret、账号或个人信息。

## 8. 全局来源熔断

以下信号必须写入同一数据源的全局状态，作用于所有工具：

- `401`、`403`：立即停止并进入授权复审；
- `429`：立即停止本任务，记录 `Retry-After`，不得切换执行来源；
- CAPTCHA、WAF、封禁页：立即停止并进入技术措施复审；
- 账号异常、异地登录提醒或安全验证：立即停止自动化；
- 投诉、律师函、平台通知或条款变化：立即转入 `QUARANTINED`。

5xx 或单纯网络超时不等于拒绝，可以在相同来源、相同身份下有限重试，不得切换代理或执行平台。

## 9. 来源侧审计回执

每次任务必须记录但不得泄露 Secret：

- 数据源 ID 和域名哈希；
- 执行出口类别；
- 是否使用登录或 API 鉴权；
- 固定 User-Agent 配置版本；
- 请求次数、页面数、并发、最小间隔；
- HTTP 状态序列和 `Retry-After` 是否出现；
- 是否发生来源切换；
- 是否触发全局熔断；
- 数据量、响应体积和清理结果。

不主动查询或公开实际出口 IP；只记录执行来源类别和受控配置。对方服务器自然会记录实际 IP，系统不得试图隐藏或污染该记录。

## 10. 不影响工作的合法降级链

```text
官方 API
→ 官方批量端点或官方下载
→ 公开网页低频只读
→ 用户本地/人工官方导出
→ 中国大陆固定执行点
→ 合法访问不可用或数据不足
```

关闭代理、验证码破解和跨来源重试不会影响正常官方 API 和公开网页读取；它只会阻断必须依靠规避措施才能完成的任务。

## 11. 生产准入

新工具或新数据源只有同时满足以下条件才能生产：

- 已登记来源服务器可见足迹；
- 已确定出口类别和账号绑定；
- 已设置跨工具全局预算；
- 已测试 401、403、429、CAPTCHA、WAF 硬停止；
- 已测试禁止换 IP、账号、Key、Cookie、User-Agent 和执行平台；
- 已生成来源侧审计回执；
- 已提供合法降级和停用路径。

现有工具采用不停机复审；发现来源切换、429 自动重试或拒绝后跨工具回退时，应立即修复相关能力。
