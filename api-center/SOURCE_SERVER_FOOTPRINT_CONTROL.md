# 中国大陆实名可追溯来源服务器足迹封控标准

## 1. 适用范围

来源服务器足迹的中国大陆专属详细封控，只适用于同时满足以下三项的活动：

1. 数据源、账号或 API 服务具有中国大陆关联；
2. 活动能够通过实名认证、手机号、身份证、银行卡、付款、账号、API Key、Cookie、Session、会员编号或服务方记录合理关联到本人；
3. 存在实质法律或账号风险，例如登录或付费访问、自动化或批量采集、授权不清、拒绝信号、敏感或非公开数据、对外发布或商业化。

普通公开网页即使记录出口 IP、User-Agent 和访问时间，只要无需登录、不使用本人账号或凭证、没有能够合理识别本人的关联记录，也不涉及受监管或非公开数据，就不进入中国大陆专属详细封控，而使用普通运行基线。

## 2. 来源服务器可能留下的记录

来源服务器可能记录：

- 出口 IP、国家或地区、云服务商和 ASN；
- TLS、浏览器和自动化指纹；
- User-Agent、Referer 和其他请求头；
- 账号、API Key 标识、Cookie、Session 与设备关联；
- 实名、手机号、身份证、银行卡、付款或企业身份绑定；
- 访问、账单、安全、审计、投诉和合同记录；
- 请求时间、频率、并发、分页、下载量和访问路径；
- 401、403、429、验证码、WAF、封禁页及后续行为。

普通匿名服务器日志本身不等于能够追溯到本人。只有能够与本人身份、账号、付款或其他识别记录合理关联时，才视为实名可追溯信号。

## 3. 封控目标

封控目标不是隐藏身份、污染记录或伪装成人工用户，而是：

```text
在实名可追溯且存在实际风险时
形成合法、稳定、最小、可解释、遇拒即停的访问轨迹
```

不得保存或输出身份证号、银行卡号、Cookie、Token 等实名值和秘密值，只记录“是否存在身份关联”、关联类型和控制结论。

## 4. 中国大陆实名 API 和登录后台

### 官方实名 API

本人实名 API 可以从固定云出口调用，但必须满足：

- 服务条款允许相应云端或境外访问；
- 只调用官方文档中的固定只读端点；
- 账号绑定一个主要执行来源，不在多个平台之间轮换；
- 遵守单账号总额度和服务方限流；
- 记录账号归属、授权范围和访问审计，不记录 Key 原文。

官方授权明确、只读且额度清楚时，不默认套用十秒间隔、二十页限制或中国大陆固定执行点。

### 本人会员后台或登录网站

优先顺序为：

```text
官方 API
→ 官方导出、SFTP 或授权镜像
→ 用户本地正常登录与导出
→ 经审计的中国大陆固定执行点
→ 服务方明确允许的专用云连接器
→ 数据不足回执
```

境外云登录中国大陆实名后台需要服务方明确允许。批量浏览器采集默认关闭。

## 5. 中国大陆匿名公开来源

无需登录、无需认证、不使用本人账号、Key、Cookie、Session、付款或订阅，且没有能够合理关联本人的记录时：

- 使用 `GLOBAL_OPERATIONAL_BASELINE`；
- 不强制中国大陆固定执行点；
- 不强制账号主要出口绑定；
- 不强制中国大陆默认十秒间隔、二十页、每小时三十次；
- 不要求中国大陆专属详细足迹回执；
- 按服务方公开规则和正常资源预算运行。

仍然只访问公开路径，不访问登录接口、隐藏接口、移动端私有接口或调试接口；遇到明确拒绝或技术措施时遵守服务方信号。

## 6. 身份与出口一致性

以下规则只对实名或身份可追溯的账号、Key、Session、会员和付款身份强制执行：

- 一个账号或 API Key 绑定一个主要执行来源类别；
- 同一任务不得在 GitHub、Cloudflare、Browserless、Apify 等执行器之间轮换来源；
- 同一来源收到拒绝后，其他工具共享熔断状态；
- 不得通过换 IP、Key、账号、Cookie、Header、User-Agent 或执行平台改变拒绝结果；
- 不得让多个工具分别消耗额度，形成跨工具叠加采集。

## 7. 请求足迹默认值

以下默认值只对 `PRC_STRICT` 中的黄色或橙色渠道生效：

- 最大并发：1；
- 最小请求间隔：10 秒；
- 单任务最大页面数：20；
- 单域名每小时最大请求数：30；
- 自动重试：仅网络超时和 5xx 可在同一来源、同一身份下有限重试；
- 401、403、429、验证码、WAF、封禁页和账号安全提醒：不得自动重试或切换来源。

官方 API 以服务方公开额度为准。匿名公开来源使用普通运行基线。

## 8. 永久禁止能力

无论能否关联本人，都不得使用：

- 住宅代理、代理池、随机 IP 或拒绝后换来源；
- 账号、Key、Cookie、设备或 User-Agent 轮换规避；
- TLS、浏览器指纹规避；
- 验证码破解、自动解除封禁；
- 隐藏接口扫描、私有移动 API 逆向；
- 漏洞利用、恶意代码；
- 未授权写入、交易和账号控制；
- 多账号或多 Key 叠加额度；
- 未经明确允许的境外云登录中国大陆实名后台。

## 9. 硬停止与审计

`PRC_STRICT` 的 401、403、429、验证码、WAF、封禁页、账号异常、平台投诉或条款变化必须进入共享硬停止。

详细回执记录：

- 数据源和域名哈希；
- 地域画像；
- 身份可追溯状态和证据类型；
- 实质风险状态；
- 执行出口类别；
- 是否鉴权；
- 请求数、页面数和状态码序列；
- 是否切换来源或触发熔断；
- 数据量和清理结果。

不得记录实际 Key、Cookie、Token、身份证号、银行卡号或其他实名秘密值。

## 10. 生产准入

生产前必须完成：

```text
中国大陆关联判定
→ 本人身份可追溯判定
→ 实质法律或账号风险判定
```

三项全部成立时才启用中国大陆专属详细足迹封控。无法确认时进入复审。匿名公开来源继续正常运行，但不得越权、规避技术措施或处理明确受限的非公开数据。
