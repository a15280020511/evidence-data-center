# GBIF 全球生物多样性数据

正式票据前缀：

```text
[intel-gbif]
```

GBIF公开REST API的大多数查询无需API Key。本连接器固定访问：

```text
https://api.gbif.org
```

开放10项受控只读能力：物种名称匹配、物种搜索与补全、分类单元读取、出现记录搜索与计数、单条出现记录读取、数据集搜索与元数据读取。

安全边界：每票据最多一次GET；不自动翻页；出现记录单页最多300条；`offset + limit`不得超过100000；不开放需要账号的异步Occurrence Download、批量导出、发布、注册、修改、删除、实验端点或GBIF网站抓取。调用结果保留原始许可证、数据集键、发布者和记录标识字段，使用方仍须遵守具体数据集许可和归属要求。
