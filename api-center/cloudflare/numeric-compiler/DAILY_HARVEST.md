# 中国情报每日免费额度采集队列

## 运行原则

```text
公开中国大陆来源
→ 标准数值数据优先确定性解析
→ 非结构化重要页面使用Cloudflare托管AI固定Schema提取
→ GitHub Actions确定性校验
→ 纯数值Parquet追加到私有Hugging Face基准库
→ 网页GPT选择并转交断网计算中心
```

每天UTC 00:15（中国标准时间08:15）启动。队列顺序为：上次额度延期任务优先，其次按创建时间处理新任务。单次只处理一个任务；达到98%估算额度、570秒浏览预算、50次请求上限、HTTP 429、Browser Run时间限制或Workers AI额度限制后立即停止。未完成任务保留到下一UTC日继续，不启用自动付费或自动外接模型。

## 创建排队任务

Issue标题：

```text
[queue-cn-numeric] 简短来源说明
```

Issue正文必须是完整JSON，不使用Markdown代码围栏：

```json
{
  "task_id": "cn-daily-example-20260804-001",
  "profile_id": "cn-listed-company-financial-report",
  "url": "https://example.cn/public-report.html",
  "data_policy": {
    "classification": "public",
    "contains_personal_data": false,
    "investment_recommendation_requested": false
  },
  "acceptance": {
    "timeout_seconds": 60,
    "max_response_bytes": 2000000,
    "minimum_confidence": 0.8
  }
}
```

可选添加标签 `cn-harvest-pending`。无队列标签的开放排队票据也会被视为待处理任务。

## 状态

- `cn-harvest-pending`：等待处理；
- `cn-harvest-active`：当前唯一执行任务；
- `cn-harvest-deferred-quota`：Cloudflare免费额度耗尽，下一UTC日继续；
- `cn-harvest-deferred-rate-limit`：平台限流或上次执行中断，下一次队列继续；
- `cn-harvest-completed`：数值数据已通过验证并入库；
- `cn-harvest-quarantined`：登录、验证码、权限、实体、单位、置信度或内容质量存在问题；
- `cn-harvest-rejected`：票据不是合法JSON或违反数据合同。

## 企业和国企数据范围

数据库结构覆盖中央企业、中央金融企业、地方国企、城投平台、大型民营企业、上市公司、重点未上市集团、在华外资企业和集团子公司，重点保存：

- 所有权、控制关系和集团结构；
- 财务、现金流、债务、债券和担保；
- 产能、产量、订单、库存、价格和成本；
- 项目投资、建设、进度、超支和实际收益；
- 采购、供应链、客户、供应商和关键依赖；
- 税收、补贴、政府采购和政策支持；
- 就业、工资、生产率和安全事件的企业级汇总；
- 研发、专利、标准和国产替代；
- 能源、资源、环境和碳排；
- 海外经营、贸易、制裁和汇率暴露；
- 监管、司法、合规、违约、重组和真实结果。

不保存个人员工轨迹、个人联系方式、非公开经营数据或原始报告正文。

## 社交平台边界

### 微博

官方开放平台或官方CLI优先。公开热搜、话题页和认证政府/企业账号页面可在无需登录且未被平台限制时由Browser Run低频采集。全网关键词检索、趋势分析和账号数据以获批接口与套餐权限为准。

### 抖音

官方开放平台优先。可使用获批的话题榜、授权账号及授权公开视频指标。公开分享页只作为机会性补充；禁止逆向移动端私有接口、签名、设备指纹或批量下载视频。

### 哔哩哔哩

官方开放平台优先，通常需要认证、应用审核或账号授权。公开排行、搜索、视频页面和认证机构账号可低频观测公开计数；禁止批量下载视频、音频、弹幕或完整评论档案。

### 知乎

开发者平台的搜索、全局搜索和热榜接口优先，以实际获批权限和商务条件为准。公开问题、话题和热榜页面可以低频提取聚合指标；禁止保存完整回答和评论正文。

### 微信视频号

只设计为本人、授权或关联主体数据，以及无需登录即可访问的公开分享页元数据。没有把视频号设计成全网公开视频通用爬虫；禁止微信客户端自动化、二维码账号池、私有社交关系和移动端私有接口逆向。

## 社交情报入库内容

只保存：

- 热榜排名、热度和变化；
- 公开浏览、点赞、评论、转发、收藏、弹幕等计数；
- 聚合传播速度、半衰期和跨平台覆盖；
- 企业、国企、政策、行业、地区和产品提及数量；
- 聚合情绪概率、质疑概率和谣言风险概率；
- 官方回应、企业回应、澄清、内容不可用等事件代码；
- 来源等级、采集完整性、失败率和交叉验证数量。

不保存原始帖子、回答、评论、视频、个人画像、私信、个人关系图、设备位置和生物特征。
