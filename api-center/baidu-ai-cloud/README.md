# 百度智能云免费情报 Provider

正式票据前缀：`[intel-baidu-ai]`。

本 Provider 只接入**有明确免费额度、适合公开情报处理、固定只读路径**的能力。统一使用一个 Repository Secret：

```text
BAIDU_AI_CLOUD_API_KEY
```

## 已开放能力

共 41 项：

- 本地治理：能力目录、免费额度与重置周期；
- 搜索研究：百度搜索、智能搜索生成、深度搜索、高性能搜索总结、深度研究 Agent 轻量版首轮；
- NLP：15 项，包括词法、情感、实体、相似度、纠错、观点、关键词、摘要、地址等；
- OCR：12 项，包括通用、高精度、办公文档、网络图片、手写、表格、印章、数字、二维码；
- 图像识别：7 项，包括场景、主体、动物、植物、Logo、地标和车辆检测。

## 免费额度重置规则

| 能力 | 免费额度形态 | 重置 |
|---|---|---|
| 百度 AI 搜索 | 官方最新总价页为每日共享免费池；端点页另载每月 1500 次按天发放 | 按日；精确结算边界以控制台为准 |
| 智能搜索/深度搜索/高性能总结 | 每日免费额度；智能搜索与百度搜索共享 | 按日 |
| 深度研究 Agent Lite | 50 次 | 官方未说明周期重置，按一次性测试额度管理 |
| NLP 个人认证 | 多数为一次性总量，有效 365 天 | 不重置 |
| NLP 企业认证部分接口 | 每日额度，有效 365 天 | 按日 |
| OCR 通用、高精度、网络图片、表格、手写、数字 | 每月额度 | 按自然月 |
| OCR 办公文档、含位置网络图片、印章、二维码 | 一次性测试次数 | 不按月重置 |
| 图像识别 | 多数为累计赠送次数，部分标注 12 个月有效 | 不按日/月重置 |
| 千帆新用户模型 Tokens | 指定模型各 100 万 Tokens，有效 3 个月 | 不重置 |

机器可读明细见 `free-quota-policy.json`。

## 免费优先与费用防护

- `web-search` 可以直接执行；
- `intelligent-search`、`deep-search`、`web-summary`、`deep-research-lite` 必须同时提交：
  - `free_quota_confirmed: true`
  - `paid_fallback_authorized: false`
- 深度搜索最多 3 个子查询，低于百度允许的最高 10 个；
- 深度研究仅允许 `lite` 首轮单请求，返回 SSE 事件后停止，不自动回答澄清问题、不自动确认大纲、不自动续跑；
- 每张票据最多一次上游请求，无自动重试、自动翻页或后台轮询。

**重要限制：** 百度没有提供可由本 Provider 查询的通用“剩余免费额度 API”。若百度控制台已开启按量后付费，免费额度耗尽后上游仍可能计费。要获得严格零费用保证，需要在百度控制台关闭或不启用按量后付费，并在使用受控高成本操作前查看剩余额度。

## 明确排除

即使部分产品有测试额度，也不接入：

- 人脸、生物识别；
- 身份证、银行卡、护照等直接身份或金融卡证 OCR；
- 语音、声纹及语音合成；
- 图像和视频生成；
- Logo 入库/删除、图库写入；
- 云资源管理和其他写操作。

这些能力不符合情报中心的公开数据、只读、低风险边界。
