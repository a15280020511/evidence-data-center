# Internet Archive Provider

Ticket prefix: `[intel-internet-archive]`

无需 Secret。固定上游为 `archive.org` 与 `web.archive.org` 的公开只读接口。

能力：

- `catalog-capabilities`
- `search-items`
- `get-item-metadata`
- `list-item-files`
- `wayback-availability`
- `wayback-captures`

不开放上传、删除、修改、登录、借阅、任意文件下载、网页正文回放抓取或批量镜像。
