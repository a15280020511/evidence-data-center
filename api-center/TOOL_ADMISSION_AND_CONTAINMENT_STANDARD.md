# 情报中心工具准入与封控标准

## 1. 适用范围

本标准适用于所有拟进入情报中心的 API、SDK、Python 包、云端浏览器、爬虫、搜索服务、数据平台、数据库、文档解析器、代理服务、MCP、Actor、插件及托管工具。

任何工具均不得因“免费”“官方”“开源”“已有账号”或“技术上可用”而直接进入生产目录。必须先完成能力审计、风险分类、最小权限封控、固定合同、测试和证据回执。

## 2. 总原则

```text
先审计 → 再封控 → 后接入
默认拒绝 → 最小开放 → 只读优先
能力可以丰富，逃逸入口必须关闭
```

情报中心继续采用 `maximum-safe-readonly`：尽量开放高价值公共读取能力，但不开放任意代码、任意网络控制、任意凭证、写操作、交易、规避型采集和私人数据处理。

## 3. 准入条件

新工具必须同时满足：

1. **身份明确**：官方服务、可信开源项目或经审计的自建适配器；第三方社区组件不得直接接触 Secret、Cookie、后台或原始数据。
2. **用途明确**：必须说明具体数据类型、目标主机、操作、输入、输出、费用、额度和保存范围。
3. **固定入口**：固定官方 HTTPS 主机、固定路径、固定操作映射；禁止任意 URL、任意 Host、任意 API 路径。
4. **最小权限**：只开放完成任务所需的最小只读能力；默认关闭写入、交易、上传、删除、账户管理和资源创建。
5. **参数受控**：参数白名单、类型、枚举、范围、分页、时间窗、区域、数量、响应大小和组合约束必须机器校验。
6. **凭证隔离**：一服务一 Secret；仅在后端注入固定官方主机；不得进入 Issue、日志、Artifact、目录或模型上下文。
7. **数据受控**：默认仅允许公开、非个人、非秘密、非重要数据；异常字段必须阻断或脱敏。
8. **停止规则**：401、403、429、CAPTCHA、WAF、封禁、权限不足、额度耗尽必须触发停止，不得通过换 IP、换 Key、换账号或修改请求继续。
9. **证据完整**：记录来源、时间、操作、参数摘要、状态、响应哈希、额度、错误和清理结果。
10. **可撤销**：必须能够独立禁用、撤销 Secret、删除目录项和回滚，不得成为其他中心的隐式依赖。

不满足任何一项，结论为 `REJECTED` 或 `QUARANTINED`，不得进入生产目录。

## 4. 风险等级

### L1：低风险只读

典型能力：官方公开 API、固定 GET、公开网页内容提取、截图、公开目录和元数据。

要求：固定主机、固定操作、单请求或有界分页、无 Cookie、无代理、无任意代码。

结论：可默认生产开放。

### L2：受控授权读取

典型能力：本人实名 API、会员数据库、本人后台正常导出、OAuth 只读、SFTP 或正式镜像服务。

额外要求：记录账号类型、授权主体、用途、期限、保存和共享范围；不得把“可见”解释为“可无限抓取或再分发”。

结论：可在专用连接器中开放。

### L3：高风险通用执行

典型能力：任意 JavaScript/Python、完整浏览器会话、Cookie/Session、自定义请求头、任意 Actor、Webhook、代理、自动翻页和长期任务。

结论：不得直接暴露给 GPT。只有经固定代码、固定目标、最小权限和人工批准后，降级为 L2 才可使用。

### L4：禁止能力

包括：住宅代理规避、验证码破解、Unblock、浏览器指纹伪装、403/429 后换身份继续、漏洞扫描、隐藏接口探测、凭证抓取、任意 Shell、任意代码执行、任意写入、交易、账号控制、完整商业数据库镜像、原始数据转售。

结论：永久禁止，不进入工具目录。

## 5. 永久关闭清单

无论上游是否免费、官方或技术上可用，以下能力默认永久关闭：

- 任意 URL、任意 Host、任意路径、任意请求头；
- 任意 Python、Shell、JavaScript、SQL 写语句和运行时安装；
- Cookie、Authorization、Token 由票据或 GPT 提交；
- Community Actor、第三方插件接触 Secret、Cookie、后台或原始数据；
- Full permissions 或账户级全资源访问；
- 住宅代理、验证码识别、自动 Unblock、反指纹和封禁规避；
- 401/403/429/CAPTCHA/WAF 后的换 IP、换 Key、换账号或代理重试；
- 多账号、多 Key 叠加同一主体额度；
- 表单提交、发布、上传、删除、修改、交易、下单和账户操作；
- 全库下载、无限分页、长期轮询和竞争性镜像；
- 个人信息、商业秘密、国家秘密、重要数据和受限测绘数据进入普通境外流程；
- 将原始会员数据、商业数据库或受版权保护全文对外再分发。

## 6. 强制停止器

```text
401 / 403
→ AUTHORIZATION_DENIED
→ 立即终止，不改变身份或请求控制字段重试
```

```text
429 / quota exhausted
→ RATE_LIMITED
→ 遵守 Retry-After；最多一次合规重试；禁止换 IP、Key 或账号
```

```text
CAPTCHA / WAF / block page
→ TECHNICAL_MEASURE_ENCOUNTERED
→ 立即终止；禁止验证码服务、代理或 Unblock
```

```text
检测到个人信息、凭证、秘密或重要数据
→ DATA_CLASSIFICATION_BLOCKED
→ 不写 Artifact；仅输出脱敏诊断
```

```text
分页、响应量、运行时间或费用超过合同
→ BOUNDED_LIMIT_EXCEEDED
→ 熔断，不自动扩大范围
```

## 7. 云端浏览器与 Apify 类工具

云端浏览器只作为固定只读渲染器或少数复杂网页的受控备用执行器，不作为万能采集器。

允许：

- 自建私有、固定版本的执行器；
- Limited permissions；
- 固定域名和只读流程；
- 最大并发 1；
- 固定页面数、时间、费用和响应上限；
- 公开网页或本人账号正常权限内数据；
- 完整日志和任务后清理。

禁止：

- 任意 Actor、任意目标、任意脚本；
- Community Actor 接触凭证；
- Full permissions；
- 住宅代理、验证码、Unblock；
- 任意 Webhook；
- 服务器拒绝后的规避重试；
- 后台个人信息和非公开数据进入境外存储。

## 8. 数据保存与再利用

数据分为三层：

1. **原始临时数据**：任务级、短期保留、不得对外提供。
2. **结构化事实数据**：保留来源、时间、单位、许可证和哈希，可进入治理核验和计算流程。
3. **版权正文或数据库集合**：默认不长期镜像；只保留标题、摘要、来源、必要引用和提取事实。

“内部分析”不得自动扩展为“公开发布、商业再分发或提供同类 API”。

## 9. 工具准入状态

每个工具只能处于以下状态之一：

- `PRODUCTION_SAFE_READONLY`：已封控，可生产使用；
- `CONTROLLED_SPECIAL_USE`：仅固定任务和人工批准；
- `QUARANTINED`：等待审计或整改；
- `REJECTED`：风险无法隔离或与现有能力重复；
- `DISABLED`：上游变化、条款变化、维护停止或发现风险后停用。

## 10. 复审触发条件

发生以下任一变化必须重新审计：

- 上游域名、API 版本、权限、套餐或条款变化；
- 新增 Cookie、代理、脚本、写入、上传、Webhook 或账户权限；
- 返回字段出现个人信息、秘密或重要数据；
- 出现 401、403、429、WAF、封禁或投诉；
- 工具维护者、所有权、依赖或供应链变化；
- 准备从内部分析扩展到对外服务或商业使用。

## 11. 生产验收

新工具进入生产前必须形成：

- 固定连接器或固定操作映射；
- 机器可读风险声明；
- 参数和响应 Schema；
- Secret 隔离证明；
- 禁止能力测试；
- 401/403/429/CAPTCHA/WAF 停止测试；
- 数据分类和脱敏测试；
- 额度、费用、超时、分页和响应体积测试；
- 日志、Snapshot、Artifact 和回滚证据。

结论必须为 `PASS` 才能进入 `api-catalog.json` 和 GPT 工具目录。

## 12. 最终规则

> 所有进入情报中心的工具，先由治理与维护流程进行能力拆解和风险封控；高风险能力默认关闭，无法封控的工具拒绝接入。GPT 只能看到已经通过审计的固定安全能力，不能直接接触上游工具的完整功能面。
