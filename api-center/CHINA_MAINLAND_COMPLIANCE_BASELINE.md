# 中国大陆法律合规基线

## 1. 唯一法律合规基线

情报中心对工具准入、数据采集、存储、处理、传输和再利用的法律判断，以中华人民共和国大陆地区现行有效的法律、行政法规、司法解释、部门规章和依法适用的强制性国家标准为唯一法律合规基线。

境外法律不作为情报中心的法律合规目标。境外服务商的使用条款、配额、技术限制和服务可用性仍作为运行条件执行；违反平台合同可能导致封号、停服或赔偿，因此不得忽略，但不替代中国大陆法律审查。

## 2. 适用重点

准入与复审至少覆盖：

- 网络安全法、数据安全法、个人信息保护法；
- 网络数据安全管理条例；
- 反不正当竞争法及网络反不正当竞争规则；
- 刑法及危害计算机信息系统安全相关司法解释；
- 著作权、商业秘密、测绘地理信息、国家秘密和数据出境规则；
- 具体行业、数据源和账号合同中的强制限制。

## 3. 不能承诺绝对零风险

任何技术和管理制度都不能保证绝对零风险，原因包括：

- 法律、司法解释、监管口径和重要数据目录可能变化；
- 上游接口、条款、字段、权限、域名和技术措施可能变化；
- 公开页面可能临时混入个人信息、秘密或受保护内容；
- 自动化任务可能出现误配置、供应链缺陷或异常返回；
- 个案责任仍由具体授权、数据、方法、规模、用途和后果共同决定。

生产目标是将可预见风险降到合理最低，并保留证据证明已采取必要、适当和持续的控制措施，不得对外宣称“绝对合法”“绝对无风险”或“保证不会被追责”。

## 4. 不影响工作的连续性原则

封控高风险能力时，优先使用合法替代路径，不直接牺牲任务目标：

```text
官方只读 API
→ 官方导出、SFTP 或正式镜像
→ 公开网页固定只读渲染
→ 本人授权后台的专用只读连接器
→ 经审批的固定私有云浏览器流程
→ 数据不足回执
```

禁止以住宅代理、验证码破解、隐藏接口、漏洞利用、换账号、换 Key 或换 IP 的方式维持任务连续性。

如果合法路径无法取得数据，系统应返回 `LEGAL_ACCESS_UNAVAILABLE` 或 `DATA_INSUFFICIENT`，不得为了“完成任务”突破授权或技术措施。

## 5. 现有工具不停机复审

现有工具采用风险分层迁移：

1. 已固定主机、固定只读、参数白名单、Secret 隔离且无高风险功能的工具，可保持运行并标记 `PROVISIONAL_SAFE_READONLY`，在存量审计中转为正式状态。
2. 出现任意代码、任意 URL、Cookie 直通、代理规避、验证码、写入、交易、Full permissions、无限分页或个人/重要数据普通出境能力的，立即禁用相关能力；安全子能力可以继续运行。
3. 无法拆分安全子能力的工具整体进入 `QUARANTINED`。
4. 存量审计不得仅检查文档，必须核验代码、Workflow、权限、Secret 注入、失败重试、日志和真实运行证据。

## 6. 新工具先审计后接入

新工具不得获得临时生产豁免。只有完成以下证据后才能进入目录：

- 中国大陆法律风险声明；
- 授权、许可证和账号范围；
- 固定主机、操作、参数及响应合同；
- 401、403、429、CAPTCHA、WAF 硬停止测试；
- 禁止代理规避、任意代码、写入和权限逃逸的负向测试；
- 数据分类、脱敏、保存和出境测试；
- 回滚、停用、Secret 撤销和审计回执。

## 7. 数据分类与境外基础设施

默认只允许公开、非个人、非秘密、非重要数据进入 GitHub、Cloudflare、Browserless、Apify 等境外基础设施。

出现以下任一情形时，不得进入普通境外流程：

- 直接或可识别个人信息；
- 身份认证信息、Cookie、Token 或其他凭证；
- 商业秘密、工作秘密、国家秘密；
- 已被告知或公开列明的重要数据；
- 受限测绘地理成果；
- 数据源合同明确禁止境外处理或第三方托管。

无法确认类别时，按较高风险处理并阻断。

## 8. 必须永久保留的硬边界

- 固定官方 HTTPS 主机和固定操作；
- 只读优先，写入、交易和账户操作默认禁止；
- 参数、分页、时间、数量、费用和响应体积有界；
- 一服务一 Secret，后端注入，不进入票据、日志、Artifact 或模型上下文；
- 401、403、429、CAPTCHA、WAF、封禁和权限不足立即停止；
- 禁止通过换 IP、Key、账号、Cookie、Header 或代理改变拒绝结果；
- 禁止任意 Python、Shell、JavaScript、运行时安装和任意 Webhook；
- 禁止完整商业数据库镜像、原始会员数据转售和受版权保护全文再分发；
- 结构化事实必须保留来源、时间、单位、许可状态和哈希。

## 9. 工作影响控制

合规封控允许产生以下有限影响：

- 某些网页无法自动化访问；
- 数据更新频率降低；
- 部分数据必须改用官方 API、导出或付费授权；
- 任务可能返回数据不足，而不是强行完成。

这些影响属于必要的法律和安全成本。不得以“工作完全不受影响”为验收标准；验收标准应为：核心合法任务可完成、替代路径明确、失败可诊断、风险能力不可逃逸。

## 10. 最终判断

中国大陆法律单一基线可以显著降低制度复杂度，并在保留最大安全只读能力的同时控制主要雷区。它能够把风险降到较低且可审计的水平，但不能消灭所有法律、合同、供应链和误操作风险，也不能保证所有任务完全不受影响。
