# 中国大陆法律合规基线

## 1. 唯一法律合规基线

情报中心对工具准入、数据采集、存储、处理、传输和再利用的法律判断，以中华人民共和国大陆地区现行有效的法律、行政法规、司法解释、部门规章和依法适用的强制性国家标准为唯一法律合规基线。

境外法律不作为情报中心的法律合规目标。境外服务商的使用条款、配额、技术限制和服务可用性仍作为运行条件执行；违反平台合同可能导致封号、停服或赔偿，因此不得忽略，但不替代中国大陆法律审查。

## 2. 中国大陆专属严格风控的触发范围

法律基线与严格技术封控范围必须分开。采用中国大陆法律作为判断基线，不等于所有中国大陆网站和公开数据都套用严格封控。

只有同时满足以下三项，才启用 `PRC_STRICT`：

1. 数据源、账号、API 服务或受监管数据具有中国大陆关联；
2. 活动能够通过实名认证、手机号、身份证、银行卡、付款、账号、API Key、Cookie、Session、会员编号或服务方记录合理关联到本人；
3. 存在实质法律或账号风险，例如登录或付费访问、自动化或批量采集、授权范围不清、拒绝信号、敏感或非公开数据、对外发布或商业化。

仅有中国大陆域名、普通出口 IP 或无法合理关联本人的匿名访问日志，不足以触发中国大陆专属严格封控。无需登录、没有本人身份绑定、没有受监管或非公开数据的中国大陆公开来源使用 `GLOBAL_OPERATIONAL_BASELINE`。

无论是否实名，盗取凭证、绕过验证码或 WAF、拒绝后换来源、漏洞利用、未授权写入、完整商业数据库复制转售等能力仍然永久禁止。

## 3. 适用重点

准入与复审至少覆盖：

- 网络安全法、数据安全法、个人信息保护法；
- 网络数据安全管理条例；
- 反不正当竞争法及网络反不正当竞争规则；
- 刑法及危害计算机信息系统安全相关司法解释；
- 著作权、商业秘密、测绘地理信息、国家秘密和数据出境规则；
- 具体行业、数据源和账号合同中的强制限制。

## 4. 不能承诺绝对零风险

任何技术和管理制度都不能保证绝对零风险，原因包括：

- 法律、司法解释、监管口径和重要数据目录可能变化；
- 上游接口、条款、字段、权限、域名和技术措施可能变化；
- 公开页面可能临时混入个人信息、秘密或受保护内容；
- 自动化任务可能出现误配置、供应链缺陷或异常返回；
- 个案责任仍由具体授权、数据、方法、规模、用途和后果共同决定。

生产目标是将可预见风险降到合理最低，并保留证据证明已采取必要、适当和持续的控制措施，不得对外宣称“绝对合法”“绝对无风险”或“保证不会被追责”。

## 5. 不影响工作的连续性原则

封控高风险能力时，优先使用合法替代路径，不直接牺牲任务目标：

```text
官方只读 API
→ 官方导出、SFTP 或正式镜像
→ 公开网页固定只读渲染
→ 本人授权后台的专用只读连接器
→ 经审批的固定私有云浏览器流程
→ 数据不足回执
```

禁止以住宅代理、验证码破解、隐藏接口、漏洞利用、换账号、换 Key 或换 IP 的方式维持任务连续性。

如果合法路径无法取得数据，系统应返回 `LEGAL_ACCESS_UNAVAILABLE` 或 `DATA_INSUFFICIENT`，不得为了“完成任务”突破授权或技术措施。

## 6. 现有工具不停机复审

现有工具采用风险分层迁移：

1. 无本人身份关联的公开只读来源，可使用 `GLOBAL_OPERATIONAL_BASELINE` 保持运行；
2. 本人实名或身份可追溯、但官方授权明确且只读的工具，可按绿色渠道保持高效率运行；
3. 本人实名后台、自动化权限不清或存在实际账号/法律风险的工具，进入黄色或橙色专用控制；
4. 出现任意代码、任意 URL、Cookie 直通、代理规避、验证码、写入、交易、Full permissions、无限分页或个人/重要数据普通出境能力的，立即禁用相关能力；安全子能力可以继续运行；
5. 无法拆分安全子能力的工具整体进入 `QUARANTINED`；
6. 存量审计不得仅检查文档，必须核验代码、Workflow、权限、Secret 注入、失败重试、日志和真实运行证据。

## 7. 新工具先审计后接入

新工具不得获得临时生产豁免。进入生产前必须完成：

- 中国大陆关联判定；
- 本人实名或身份可追溯判定；
- 实质法律或账号风险判定；
- 授权、许可证和账号范围；
- 固定主机、操作、参数及响应合同；
- 401、403、429、CAPTCHA、WAF 硬停止测试；
- 禁止代理规避、任意代码、写入和权限逃逸的负向测试；
- 数据分类、脱敏、保存和出境测试；
- 回滚、停用、Secret 撤销和审计回执。

三项严格范围条件全部成立时使用 `PRC_STRICT`；否则使用 `GLOBAL_OPERATIONAL_BASELINE`。无法确认时进入复审。

## 8. 数据分类与境外基础设施

身份可追溯与数据内容风险独立判断。即使来源无法关联本人，出现以下任一情形时也不得进入普通境外流程：

- 直接或可识别个人信息；
- 身份认证信息、Cookie、Token 或其他凭证；
- 商业秘密、工作秘密、国家秘密；
- 已被告知或公开列明的重要数据；
- 受限测绘地理成果；
- 数据源合同明确禁止境外处理或第三方托管。

无法确认类别时，按较高风险处理并阻断。

## 9. 必须永久保留的硬边界

- 固定官方 HTTPS 主机和固定操作；
- 只读优先，写入、交易和账户操作默认禁止；
- 参数、分页、时间、数量、费用和响应体积有界；
- 一服务一 Secret，后端注入，不进入票据、日志、Artifact 或模型上下文；
- 401、403、429、CAPTCHA、WAF、封禁和权限不足立即停止；
- 禁止通过换 IP、Key、账号、Cookie、Header 或代理改变拒绝结果；
- 禁止任意 Python、Shell、JavaScript、运行时安装和任意 Webhook；
- 禁止完整商业数据库镜像、原始会员数据转售和受版权保护全文再分发；
- 结构化事实必须保留来源、时间、单位、许可状态和哈希。

## 10. 最终判断

中国大陆法律作为判断基线，但中国大陆专属严格封控只聚焦于能够合理追溯到本人实名或身份记录、并形成实际法律或账号风险的活动。匿名公开来源不套重规则；实名授权明确的官方渠道保持高效率；实名后台和授权不清渠道加强控制；越权和规避能力永久禁止。
