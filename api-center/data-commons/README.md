# Google Data Commons managed provider

"
    "Standalone REST V2 provider using Repository Secret `GOOGLE_DATA_COMMONS_API_KEY`. "
    "The key is injected only through the backend `X-API-Key` header and is never written to logs, Issues or Artifacts.

"
    "Allowed operations: `catalog-capabilities`, `resolve-place`, `resolve-indicator`, "
    "`node-properties`, and `observations`. Arbitrary URLs, SPARQL, NL API, MCP, writes and personal-data queries are disabled.
"
