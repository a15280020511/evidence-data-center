# 中国大陆数据来源渠道分级封控

## 目标

中国大陆来源不采用统一强度的封控。系统先识别渠道，再施加完成合法任务所需的最低控制：

```text
绿色：直接生产
黄色：轻量受控
橙色：专用连接器或本地/境内执行
红色：永久禁止
```

渠道等级与数据内容等级相互独立。即使渠道为绿色，实际返回个人信息、重要数据、商业秘密或受限测绘数据时，也必须升级审查或阻断。

## 绿色渠道：正常使用，不套会员后台重规则

包括：

- 中国大陆政府、事业单位和公共机构的官方开放 API；
- 本人实名申请、文档明确、只读的官方 API；
- 官方开放数据文件、批量下载端点；
- 官方导出、SFTP 或明确授权镜像；
- 政府和公共机构无需登录的静态页面；
- 官方公开 PDF、公告、统计表和附件。

绿色渠道保留固定主机、只读操作、Secret 隔离、官方额度、数据分类、来源和许可证记录、响应上限及审计回执。不会默认套用“每次间隔十秒、最多二十页、必须中国大陆执行点”等重规则。

官方 API 直接遵守服务方公布的额度。官方批量数据优先一次下载、缓存和去重。无明确额度的政府静态网页默认最大并发 2、最小间隔 2 秒、单任务最多 100 页；数据源另有规则时以官方规则为准。

## 黄色渠道：可正常生产，但保持低频只读

包括：

- 无需登录的商业或非政府公开网页；
- 需要浏览器渲染的公开动态页面；
- 第三方聚合 API；
- 搜索引擎及搜索 API；
- 用于聚合信号的社交平台公开页面；
- 公开新闻、报告、研究和数据库展示页。

默认并发 1、最小间隔 10 秒、单任务最多 20 页、单域名每小时最多 30 次。只允许固定公开路径、GET 或只读渲染，遇到 401、403、429、验证码、WAF 或封禁页立即停止。

黄色渠道允许保存经过验证的结构化事实、数值、聚合指标和短摘要；不保存个人画像、原始社交内容、完整新闻或报告镜像，也不复制完整数据库。

## 橙色渠道：不是禁止，而是专用封装

包括：

- 本人注册并登录的网站账号；
- 付费会员或订阅后台；
- 带 Session 的云浏览器；
- 自动化或批量权限不明确的网站；
- 账号绑定导出但没有自动化许可的渠道；
- 许可证范围不清楚的数据源；
- 高精度地理、关键基础设施、金融或行业敏感数据。

优先顺序为：

```text
官方 API
→ 官方导出、SFTP 或授权镜像
→ 本地正常登录或人工导出
→ 经审计的中国大陆固定执行点
→ 服务方明确允许时使用专用云连接器
→ 数据不足
```

一个账号或 Key 绑定一个主要执行来源。境外云登录中国大陆后台需要服务方明确允许。批量采集默认关闭，页数、导出量、间隔和保存范围按数据源单独审查。原始后台页面和文件只做任务级临时保存，清洗后删除。

## 红色渠道：永久禁止

包括：

- 借用、购买、盗取、共享账号或凭证；
- 由任务或模型传入 Cookie、Token 或 Authorization；
- 绕过验证码、WAF、封禁或限流；
- 住宅代理、代理池、随机 IP 或拒绝后切换来源；
- 扫描隐藏接口、逆向私有移动 API；
- 漏洞利用或恶意代码；
- 未授权写入、交易、账号控制；
- 完整数据库镜像、原始数据转售；
- 私信采集、个人画像；
- 国家秘密、商业秘密或明确受限的非公开数据。

任何工具只有依赖这些能力才能工作时，不得进入生产。

## 自动升级和硬停止

- 出现个人信息：阻断普通流程，另行判断是否存在合法个人信息处理基础；
- 出现重要数据或受限测绘：阻断普通境外和普通入库流程；
- 出现商业秘密或非公开后台数据：阻断并隔离；
- 许可证不明：升级为橙色；
- 条款、接口权限或数据类型变化：重新审查；
- 401、403、429、验证码、WAF、账号安全提醒：所有工具和来源共享硬停止；
- 从内部分析变为公开发布、转售或对外服务：重新分级。

## 原点案例共同雷区

原点专项检索显示，案件风险通常不是由“存在 API、账号、自动化或境外 IP”单独产生，而是由以下组合形成：

- 超越接口或账号权限；
- 未取得平台和必要用户授权；
- 合作或授权终止后仍继续使用数据；
- 避开技术措施或收到拒绝后继续；
- 高频、批量、长期复制；
- 获取用户信息、认证信息或非公开数据；
- 建立替代服务、完整数据库或对外牟利。

因此，官方公开渠道应保持高效率；账号后台和不明许可证渠道应专用封装；规避和越权渠道必须永久禁止。
