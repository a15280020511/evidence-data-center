# 中国大陆实名可追溯来源分级封控

## 目标

中国大陆专属封控只针对能够合理关联到本人实名或身份记录、并且存在实质法律或账号风险的活动。

严格封控必须同时满足：

```text
中国大陆关联
+ 本人实名或身份可追溯
+ 实质法律或账号风险
```

普通中国大陆公开网页如果无需登录、没有本人账号或 Key、没有付款或 Session 绑定，除匿名访问日志外也不能合理关联到本人，并且不涉及受监管或非公开数据，则使用普通运行基线，不套中国大陆专属重规则。

渠道等级与数据内容等级相互独立。实际返回个人信息、重要数据、商业秘密或受限测绘数据时，必须升级审查或阻断。

## 绿色渠道：实名可追溯但官方授权明确

包括：

- 本人实名申请、文档明确、只读的中国大陆官方 API；
- 本人身份关联的政府或公共机构官方开放 API；
- 官方开放数据文件、批量下载端点；
- 官方导出、SFTP 或明确授权镜像；
- 官方公开 PDF、公告、统计表和附件；
- 服务方明确允许的只读云端调用。

绿色渠道保留账号归属、授权范围、Secret 隔离、官方额度、数据分类、来源和许可证记录及审计回执。不会默认套用“每次间隔十秒、最多二十页、必须中国大陆执行点”等重规则。

官方 API 直接遵守服务方公布的额度。官方批量数据优先一次下载、缓存和去重。

## 黄色渠道：实名可追溯的公开或聚合渠道

包括：

- 使用本人 Key、账单或账号的第三方聚合 API；
- 使用本人身份关联凭证的搜索 API；
- 带本人账号、账单或会话记录的公开动态页面；
- 本人身份可追溯的社交平台公开信号采集；
- 本人身份可追溯的公开新闻、报告、研究和数据库展示页。

默认并发 1、最小间隔 10 秒、单任务最多 20 页、单域名每小时最多 30 次。只允许固定公开路径、GET 或只读渲染，遇到 401、403、429、验证码、WAF、封禁页或账号安全提醒立即停止。

如果同类公开来源完全没有本人身份关联，则不进入黄色渠道，直接使用普通运行基线。

## 橙色渠道：实名后台或授权不清

包括：

- 本人实名认证并登录的网站账号；
- 付费会员或订阅后台；
- 带 Session 的云浏览器；
- 自动化或批量权限不明确的网站；
- 账号绑定导出但没有自动化许可的渠道；
- 许可证范围不清楚的数据源；
- 高精度地理、关键基础设施、金融或行业敏感数据。

优先顺序为：

```text
官方 API
→ 官方导出、SFTP 或授权镜像
→ 本地正常登录或人工导出
→ 经审计的中国大陆固定执行点
→ 服务方明确允许时使用专用云连接器
→ 数据不足
```

一个实名账号或 Key 绑定一个主要执行来源。境外云登录中国大陆实名后台需要服务方明确允许。批量采集默认关闭，页数、导出量、间隔和保存范围按数据源单独审查。原始后台页面和文件只做任务级临时保存，清洗后删除。

## 红色渠道：全球永久禁止

包括：

- 借用、购买、盗取、共享账号或凭证；
- 由任务或模型传入 Cookie、Token 或 Authorization；
- 绕过验证码、WAF、封禁或限流；
- 住宅代理、代理池、随机 IP 或拒绝后切换来源；
- 扫描隐藏接口、逆向私有移动 API；
- 漏洞利用或恶意代码；
- 未授权写入、交易、账号控制；
- 完整数据库镜像、原始数据转售；
- 私信采集、个人画像；
- 国家秘密、商业秘密或明确受限的非公开数据。

红色禁令不以是否实名为前提。任何工具只有依赖这些能力才能工作时，不得进入生产。

## 自动升级和硬停止

- 发现活动能够关联到本人：重新执行实名可追溯范围判断；
- 发现实质法律或账号风险：重新执行严格范围判断；
- 出现个人信息：阻断普通流程，另行判断合法处理基础；
- 出现重要数据或受限测绘：阻断普通境外和普通入库流程；
- 出现商业秘密或非公开后台数据：阻断并隔离；
- 许可证不明：升级为橙色；
- 条款、接口权限或数据类型变化：重新审查；
- 401、403、429、验证码、WAF、账号安全提醒：共享硬停止；
- 从内部分析变为公开发布、转售或对外服务：重新分级。

## 判定原则

风控对象不是“中国大陆网站”本身，而是：

```text
能够通过实名、账号、付款、Key、Cookie、Session或服务方记录追溯到本人
并且会形成实际法律责任、合同责任、账号处罚或数据合规风险的活动
```

普通匿名公开访问不实施中国大陆专属重封控；实名可追溯但官方授权明确的渠道保持高效率；实名后台和授权不明渠道使用专用封装；规避和越权能力永久禁止。
