# 高风险第三方来源监测

此目录只保存需要持续观察、但未获准成为生产连接器的第三方来源和封装项目。

## 边界

- 仅读取公开仓库元数据、README、清单、Release、许可证和安全信号。
- 不安装或执行候选代码。
- 不下载书籍、文档或其他受版权限制内容。
- 不解析直接下载链接，不绕过验证码、反自动化、访问控制、限流或付费墙。
- 不提交凭据，不启用计费，不把监测对象自动升级为生产依赖。

## 发现方式

第一阶段使用不包含目标专名的宽泛查询发现类别候选。最近变化查询按更新时间排序，类别盲发现使用GitHub最佳匹配，并有独立的25条上限。例如：

```text
archive api language:Python
bibliographic metadata SDK
digital library catalog API
```

生产工作流必须在全球候选Artifact中证明：至少一个已知Watchlist候选确实由上述无专名查询重新发现。只存在静态专名种子而没有宽泛命中时，盲发现验收失败。

第二阶段才对第一阶段命中的项目做名称、别名、Fork来源、维护状态、许可证和安全核验。专名种子用于持续监测，不用于伪造“宽泛搜索命中”。

任何进一步接入必须经过版权与条款、许可证、维护者来源、依赖安全、隔离测试和治理审批。
