# 信息工具雷达（Information & Tool Radar）

这是情报中心内部独立的、只读的全球发现区域。它不承担正式分析、推演或生产依赖升级，只负责发现、核验、归一化和报告：

- 全球公开信息源、数据源、资料库和历史页面；
- 情报中心可用的搜索、浏览、抽取、OCR、知识图谱、MCP、SDK和连接器；
- 由情报中心代搜的计算中心统计、因果、优化、仿真、博弈和金融工具；
- 已接入API、MCP、软件包、模型和数据集的版本、功能、价格、许可和安全变化。

## 独立边界

```text
api-center/information-tool-radar/
├── config.json               # 适配器、查询、额度和覆盖目标
├── radar.py                  # 基础标准库执行器
├── radar_v2.py               # 独立备源和韧性入口
├── test_radar.py             # 离线确定性回归测试
├── candidate.schema.json     # 统一候选记录合同
└── README.md
```

独立工作流：`.github/workflows/information-tool-radar.yml`。

## 第一阶段适配器

| 适配器 | 覆盖面 | 独立降级路径 |
|---|---|---|
| Common Crawl | 当前网络和长尾网页索引 | URL节点异常时保留官方索引目录并标记降级 |
| Wayback CDX | 删除、改版和历史版本网页 | Internet Archive → Arquivo.pt |
| GDELT | 全球新闻、事件、人物、组织和地区线索 | DOC API → Web NGrams官方更新清单 |
| Wikimedia RecentChanges | 多语言新实体、别名和知识变化 | 12种语言逐站串行、`maxlag`与退避 |
| DataCite | 数据集、研究软件和DOI资料 | 故障单独报告，不隐藏 |
| Crossref | 论文、研究资料和DOI元数据 | 作为研究资料类别的独立备源 |
| PyPI RSS | 新增和更新的Python软件包 | 官方RSS |
| OSV | 软件包漏洞和安全变化 | 批量只读查询 |
| GitHub Search | 开源工具、MCP、SDK、连接器和计算框架 | 多个短能力查询族 |

## 八类覆盖域

```text
当前网页
历史网页
全球事件
多语言实体
科研资料
软件包
软件安全
代码与工具
```

DataCite和Crossref属于同一个科研资料覆盖域，但作为两个独立适配器分别计算健康状态。单一服务故障不会被隐藏，也不会直接使整个覆盖域失效。

## 运行原则

1. 官方注册表和机器可读Feed优先，网页搜索只用于补漏。
2. 只读取公开元数据和少量有界样本，不下载大文件。
3. 不安装或执行发现的包、MCP、容器、二进制和浏览器扩展。
4. 不提交密钥，不启用计费，不进行写操作。
5. PR阶段可以读取公开零费用端点做覆盖验收，但不得写入主分支。
6. 新候选只进入候选库；正式接入必须经过免费、许可、安全、回归、基准和治理审批。
7. 计算中心继续保持断网；计算工具由本雷达代搜，批准后才交给计算中心离线评测。
8. 工作流启用`pipefail`，覆盖报告FAIL必须导致Actions失败，禁止绿色状态掩盖真实失败。

## 覆盖验收

当前门槛：

- 独立适配器成功率不低于85%；
- 八类候选覆盖率不低于85%；
- 所有失败、限流、超时和降级路径写入报告；
- 不因备源成功而删除主源故障证据。

每次运行输出：

- 适配器成功率；
- 八类覆盖域命中率；
- 多语言端点成功率；
- 每类查询候选产出；
- 唯一候选、唯一域名和重复率；
- 失败端点、空结果和限流情况；
- 未覆盖类别、语言和能力；
- 标准化候选JSONL和Artifact清单。

本雷达不能宣称“全球绝对无死角”，只报告可度量覆盖、信号质量、降级状态和明确盲区。
