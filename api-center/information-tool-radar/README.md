# 信息工具雷达（Information & Tool Radar）

这是情报中心内部独立的、只读的全球发现与现有能力监测区域。它不承担正式分析、推演或生产依赖自动升级，只负责发现、盘点、核验、归一化、指纹比较和报告：

- 全球公开信息源、数据源、资料库和历史页面；
- 情报中心可用的搜索、浏览、抽取、OCR、知识图谱、MCP、SDK和连接器；
- 由情报中心代搜的计算中心统计、因果、优化、仿真、博弈和金融工具；
- 已接入API、MCP、软件包、模型和数据集的版本、功能、价格、许可和安全变化。

## 两条独立轨道

### 全球增量雷达

用于发现新的信息来源、情报工具、计算工具和外部变化候选。泛化搜索负责找新增对象，不负责证明现有工具全部存在。

### 现有工具种子监测

从仓库正式合同确定性盘点所有现有工具，逐项生成SHA-256能力指纹、固定监测查询和七日轮换计划。现有工具不依赖随机搜索碰巧重新命中。

## 现有工具监测合同

现有工具清单来自：

- `api-center/connector-manifest.json`中的已启用普通连接器；
- 各工具目录的`provider-catalog.json`、能力合同和固定任务入口；
- 去重后的正式服务族和内部能力模块。

每个工具保存：

- 规范化工具ID和别名；
- 正式合同文件路径；
- SHA-256能力指纹；
- 官方或固定外部定位信息；
- 本地合同、官方文档、SDK、Release、Changelog、弃用、价格、许可和漏洞监测信号；
- 七日轮换桶。

每次运行比较：

```text
new_tools
removed_tools
changed_tools
unchanged_tools
```

指纹变化只生成报告，不自动升级生产依赖。正式调整必须经过安全、许可、费用、回归、基准和治理审批。

## 运行原则

1. 官方注册表和机器可读Feed优先，网页搜索用于补漏。
2. 只读取公开元数据和少量有界样本，不下载大文件。
3. 不安装或执行发现的包、MCP、容器、二进制和浏览器扩展。
4. 不提交密钥，不启用计费，不进行外部写操作。
5. 新候选只进入Artifact；正式接入必须经过治理审批。
6. 计算中心继续保持断网；计算工具由本雷达代搜，批准后才交给计算中心离线评测。
7. 工作流启用`pipefail`，覆盖报告FAIL必须导致Actions失败。
8. 必需适配器和可选监测适配器分开计量，任何故障仍保留证据。

## 验收门

当前强制门：

- 必需适配器成功率不低于85%；
- 八类候选覆盖率不低于85%；
- 正式现有工具盘点覆盖率必须为100%；
- 正式现有工具指纹覆盖率必须为100%；
- 正式现有工具种子监测覆盖率必须为100%；
- 所有失败、限流、超时和降级路径写入报告。

泛化全球搜索单轮重新命中率不作为现有工具覆盖门。该指标用于评估搜索质量和生成补搜词；现有工具全覆盖由确定性种子监测保证。
